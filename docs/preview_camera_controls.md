# Preview Camera Controls

The preview panel supports:

- Reset Camera
- Fit to View
- Isometric
- Front
- Side
- Top
- Perspective/orthographic toggle

After loading a preview, the GUI uses an isometric view, resets the camera, and
adds visual padding so the object is not framed too tightly.

Clipping controls:

- Clip X
- Clip Y
- Clip Z
- invert clipping
- slice overlay
- plane position slider

Clipping and slicing are display operations only. Exported geometry is
unchanged.
