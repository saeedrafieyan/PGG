# Terminology Registry

Phase 3B.1 uses controlled terminology to avoid collapsing distinct scientific
concepts.

## Sphere-Pore Structures

- SC: Simple Cubic
- BCC: Body-Centered Cubic / Body Centred Cubic
- FCC: Face-Centered Cubic / Face Centred Cubic
- HCP: Hexagonal Close-Packed

## TPMS

- gyroid
- diamond / diamond TPMS
- primitive / primitive TPMS

## Domain

- box
- cuboid
- rectangular prism
- cylinder / cylindrical

## Pore Terms

- generating sphere diameter: input sphere diameter for sphere-pore generators
- equivalent pore diameter: measured geometric pore diameter
- throat diameter: measured opening between pores
- pore opening: throat/opening language, not generating diameter
- unit-cell size: TPMS spatial period
- lattice spacing: sphere-center spacing
- wall/strut thickness: unsupported final validators in this phase

## Export

STEP and STP refer to the same STEP exchange format family. STEP/STP requests
are recognized, retained as future requirements, and reported as unsupported in
accepted production output for Phase 3B.1.
